# Contributing to AIRA

We welcome all contributions! AIRA is a community-first project.

## How to Contribute
1. **Report bugs** – Open a GitHub Issue with clear steps to reproduce.
2. **Suggest features** – Create an Issue with the "enhancement" label.
3. **Write code** – Fork the repo, create a branch, and submit a Pull Request.
4. **Improve docs** – Fix typos, add clarity, write tutorials.
5. **Test & give feedback** – Build AIRA yourself and share your experience.

## Pull Request Process
1. Fork the repository.
2. Create a feature branch (`git checkout -b feature/amazing-feature`).
3. Commit your changes (`git commit -m 'Add amazing feature'`).
4. Push to the branch (`git push origin feature/amazing-feature`).
5. Open a Pull Request with a clear description.

## Code of Conduct
Be kind, be respectful, be constructive. Full Code of Conduct coming soon.

## Questions?
Open a Discussion or reach out to the maintainers.
