# AIRA – Software Stack (Fully Open-Source)

## Pendant Firmware
**Owl / Omi** – MIT License  
Ready-to-flash firmware for XIAO ESP32S3 Sense. Handles always-on VAD, wake-word detection, and real-time audio streaming.

## Speech-to-Text
**whisper.cpp** – MIT License  
High-performance local transcription with automatic 30+ language detection.

## Voice Activity Detection
**Silero VAD** – MIT License  
Lightweight neural network distinguishing speech from silence/noise.

## Speaker Diarization
**pyannote.audio** – MIT License  
Automatic speaker segmentation into labelled chunks ("Speaker 1", "Speaker 2"…).

## Local LLM Serving
**Ollama** – MIT License  
Inference engine for local LLMs with OpenAI-compatible API. Models: llama3.2:1b, tinyllama, qwen2.5:3b.

## Memory & Knowledge
**Letta (MemGPT)** – Apache 2.0  
Self-editing long-term memory framework. Auto-decides what to store, recall, and forget.

## Text-to-Speech
**Piper TTS** – MIT License  
Fast, offline neural TTS in multiple languages and voices.

## Fine-Tuning
**Unsloth** – Apache 2.0  
Memory-efficient LLM fine-tuning framework for periodic model improvement.

## Backend Orchestration
**Pipecat** – BSD 2-Clause  
Real-time voice AI pipeline framework handling service orchestration.

## User Interface
**Open WebUI** – MIT License  
Self-hosted ChatGPT-style web dashboard with multi-user support.

**Total Software Cost: €0**
